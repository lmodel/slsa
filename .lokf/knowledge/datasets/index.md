# Datasets

* [slsa LinkML schema](slsa-linkml-schema.md) - The modular LinkML schema of the SLSA specification v1.2 (schema id `https://w3id.org/lmodel/slsa`): `slsa.yaml` imports a core module and one module per track, predicate or study, covering the Build, Source, Dependency and Build Environment tracks and the in-toto statement layer; its `lokf adapt` copy in `.lokf/slsa.yaml` is the bundle's domain schema.
* [SLSA specification copy](slsa-spec-copy.md) - The SLSA specification's Markdown pages, images and provenance schemas (.proto, .cue) copied into `src/slsa/schema/spec/`: all 39 files are identical to `docs/spec/draft/` at SLSA tag v1.2, and a weekly workflow watches for a newer release.
* [Generated artifacts](generated-artefacts.md) - Files generated from the slsa schema and never edited by hand, committed or git-ignored: the two merged schemas in docs/schema/, the Python data models, project/ (JSON Schema, OWL, SHACL, Java and more), docs/elements/ and the bundle's domain schema .lokf/slsa.yaml.
* [Test data](test-data.md) - Example YAML instances of the slsa schema in tests/data/, valid and invalid, named ClassName-###.yaml after the class they instantiate (InTotoStatement, SlsaBuildPlatform and the rest); pytest and linkml-run-examples check them.
