# Glossary

* [SLSA track](slsa-track.md) - A track groups SLSA levels that measure one aspect of supply chain security (Build, Source, Dependency or Build Environment), so progress on one aspect is recognised without blocking on another.
* [SLSA level](slsa-level.md) - A rung within a SLSA track, such as Build L2 or Source L3, each giving a stronger supply chain security guarantee than the one below; the schema names them in its four level enums.
