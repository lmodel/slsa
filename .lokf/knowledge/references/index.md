# References

* [SLSA specification](slsa-specification.md) - Supply-chain Levels for Software Artifacts (SLSA), the OpenSSF specification of tracks and levels for supply chain security that the slsa LinkML schema encodes; the schema's docs name v1.2 as the target.
* [CNCF Secure Software Factory whitepaper](secure-software-factory.md) - The CNCF TAG-Security Secure Software Factory whitepaper (2022), a reference architecture for an end-to-end SLSA pipeline; the schema's slsa_ssf subset draws on it.
* [SLSA adoption study (Tamanna et al., 2024)](slsa-adoption-study.md) - An empirical study of SLSA adoption in open source projects (arXiv:2409.05014), whose challenge and strategy themes the schema's slsa_adoption_study subset encodes as enums and slots.
* [OpenSSF Software Supply Chain working group](openssf-supply-chain.md) - The OpenSSF working group that coordinates SLSA, Sigstore, GUAC, gittuf, Security Insights and related projects; the schema cross-references them in notes and see_also annotations.
